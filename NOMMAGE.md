Composants 

- `button` : utilisé sur toutes les pages. Éléments : `button__icon`. Modificateurs : `button--primary`, `button--secondary`, `button--light`, `button--small`, `button--large`, `button--icon`, `button--loading`.
- `badge` : accueil, programme, artistes. Élément : `badge__count`. Modificateurs : `badge--lake`, `badge--forest`, `badge--kiosk`, `badge--new`, `badge--last`, `badge--full`, `badge--small`, `badge--large`, `badge--outline`, `badge--square`, `badge--program`.
- `card` : accueil, programme, artistes. Éléments : `card__media`, `card__body`, `card__title`, `card__meta`, `card__text`, `card__link`, `card__actions`. Modificateurs : `card--plain`, `card--featured`, `card--compact`, `card--horizontal`, `card--lake`, `card--forest`, `card--kiosk`.
- `pass` : billetterie. Éléments : `pass__title`, `pass__price`, `pass__list`, `pass__item`, `pass__action`, `pass__flag`. Modificateur : `pass--highlight`.
- `scene-banner` : accueil et pages artistes. Éléments : `scene-banner__title`, `scene-banner__text`, `scene-banner__link`. Modificateurs : `scene-banner--lake`, `scene-banner--forest`, `scene-banner--kiosk`.
- `info` : infos pratiques. Éléments : `info__index`, `info__title`, `info__text`.
- `field` : billetterie. Éléments : `field__label`, `field__input`, `field__help`, `field__error`. Modificateur : `field--check`.
- `filter` : programme. Élément : `filter__item`.
- `faq` : infos pratiques. Éléments : `faq__question`, `faq__answer`.
- `hero` : se trouve en haut de la page d'accueil.
- `artist` : utilisé sur les pages artistes.



Préfixes
- `l-` : mise en page (ex. `l-header`, `l-footer`)
- `is-` : états (ex. `is-active`, `is-open`, `is-hover`, `is-focus`)
- `has-` : état porté par un parent (ex. `has-error`)
- `theme-` : thèmes (ex. `theme-lake`, `theme-dark`)
